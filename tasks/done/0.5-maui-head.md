# Step 0.5 — `Shows.App` MAUI head + DI wiring

## Read
- `docs/ARCHITECTURE.md §3` — the project graph. `Shows.App` is the composition root: it is the only
  place the UI and Infrastructure edges meet, and it is the only project that may reference both
  `Shows.Application` (transitively) and `Shows.Infrastructure`. `Shows.App` and `Shows.Infrastructure`
  must not reference each other's consumers.
- `docs/ARCHITECTURE.md §7` — logging is configured once via `AddShowsLogging()`; the app gets no sinks
  or levels of its own.
- `docs/IMPLEMENTATION_PLAN.md step 0.5` — acceptance criteria.
- `docs/STATE.md` — the step-0.5 machine blocker (now resolved): the .NET 8 MAUI packs.

## Do
- Scaffold `Shows.App` as a **Windows-only, unpackaged** MAUI app: `net8.0-windows10.0.19041.0`,
  `UseMaui=true`, `SingleProject=true`, `WindowsPackageType=None`, `OutputType=WinExe`. Trim the
  `dotnet new maui` template to the Windows head only (no Android/iOS/Tizen/Mac Catalyst platforms).
- `MauiProgram.CreateMauiApp()` is the composition root: `AddShowsLogging` → `AddShowsInfrastructure`
  → fonts → `UseMauiApp<App>`, then a synchronous storage init that ensures the data directories and
  runs the **gated** `ShowsDatabaseMigrator.MigrateAsync()`.
- Reference `Shows.Infrastructure` (the only such edge) and `CommunityToolkit.Mvvm` for later phases.
- Shell + a placeholder `MainPage` so the app launches; no real UI until Phase 4/5.

- [x] `Shows.App` is the only project that references `Shows.Infrastructure` from the UI side; the

## Constraints
- `Application` is ambiguous in the `Shows.App` namespace: it collides with the `Shows.Application`
  namespace, and namespace-member lookup outranks a `using` alias (CS0118). Fully qualify the base type
  as `Microsoft.Maui.Controls.Application` in `App.xaml.cs`.
- `UseMaui=true` on the net8 TFM requires the .NET 8 MAUI **packs** (`Microsoft.Maui.Sdk\8.0.3`), not
  just the workload manifest. This was the machine blocker; it is resolved.
- MA002: add explicit `Microsoft.Maui.Controls` + `.Compatibility` package refs (`$(MauiVersion)`);
  the implicit refs are not enough on this SDK.
- `NoWarn=CA5392;CA1724` is scoped to `Shows.App` only (P/Invoke + namespace-vs-type naming in the
  generated Windows head) — never solution-wide.
