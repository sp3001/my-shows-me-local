# Step 3.1 — `TvmazeCatalogProvider`

## Read
- `docs/ARCHITECTURE.md §5` — one `HttpClient` per host via `IHttpClientFactory`, versioned
  `User-Agent`, Polly retry (exponential, jitter) + circuit breaker, `http_cache` keyed by URL with
  `ETag`/`Last-Modified` revalidation, all requests to one host **serial** (`SemaphoreSlim(1,1)`).
- `docs/ARCHITECTURE.md §4` — `Proxy`/`Http` are read in ONE place (the handler config in
  `AddShowsInfrastructure`); no caller builds its own client or inspects a URL to route (SPEC R14).
- `docs/SCHEMA.md §2` — `http_cache` (url PK, etag, last_modified, body, fetched_at). Transport-layer
  only; **not a source table** — the mapper must never read it.
- `docs/DATA_ANALYSIS.md §8` — the recorded Black Mirror show + episode payloads (the exact JSON shape).
- `docs/DATA_ANALYSIS.md §9` — TVmaze is **unreachable directly**, reachable via `main-pc:10801`. A
  transport failure surfaces as a timeout/reset, never as "no data" (R14).
- `docs/IMPLEMENTATION_PLAN.md step 3.1` — acceptance criteria (below).

## Do
- `TvmazeCatalogProvider` (Infrastructure, over the `Tvmaze` named client) implements **both** seams:
  `ICatalogProvider` (Application) and `ITvmazeShowSource` (Infrastructure). Registering it wires the
  mapper's `MapShowAsync(int)` fetch path (the DI line already resolves it via `GetService`).
- Methods: `SearchAsync`, `GetShowAsync`, `GetEpisodesAsync`, `LookupByImdbIdAsync`, `GetNewShowsAsync`,
  `GetUpcomingAsync`. DTOs mapped to source rows / `CatalogShow` at the boundary.
- `http_cache` revalidation: send `If-None-Match`/`If-Modified-Since`; on 304 reuse the cached body;
  on 200 store the new body + etag/last-modified.
- Polly: retry (exponential + jitter) + circuit breaker, **but must not retry a proxy transport failure
  as if it were a provider 5xx** (retrying a dead proxy multiplies the connect timeout).
- **R14:** an unreachable host surfaces as a failed task naming the host, NEVER an empty list.

## Acceptance criteria
- [x] Tests against recorded JSON fixtures, **no network** (10 tests, fake `IHttpClientFactory` over a controllable handler).
- [x] One test asserts a cached response is **revalidated** (304 → reuse), not refetched (handler asserts the `If-None-Match` header arrived and counts exactly one revalidation).
- [x] Recorded in `LOG.md`: every successful call took the **proxy** (direct failed with a connect
      timeout); 10 searches under the throttle returned all 200 with no 429/`Retry-After`; the observed
      `status` set is `{Running→Airing, Ended→Ended}`, both mapped (no `mapped_to NULL`). The live probe
      also caught the `/search/shows` score-envelope bug (DATA_ANALYSIS §8 fact 14).

## Constraints
- Use the `Tvmaze` named client only. Serial per host (the `ThrottlingHandler` already does this).
- `http_cache` is written by the provider (transport layer) and read by nothing but the provider.
- The provider must not write source tables — fetching is its job; writing them is the mapper's.
