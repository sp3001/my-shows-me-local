# Step 7.5 — Localized titles from TVmaze `/akas`

## Read
- `docs/IMPLEMENTATION_PLAN.md §Step 7.5` — the seam, source table, job shape, and verify criteria (copied below).
- `docs/SCHEMA.md §3 (tvmaze_akas)` — the composite PK `(tvmaze_show_id, country_code, name)` and `aka_order`.
- `docs/SPEC.md R11/R14` — the mapper is the sole mapped-row writer; an unreachable host throws, never empty.
- `docs/DATA_ANALYSIS.md §8` — the live-probed `/akas` shape (keys on `country.code`, not language).

## Do
- `tvmaze_akas` source entity + DbSet + composite-PK config + migration `0005`.
- `ICatalogProvider.GetAkasAsync(int)` returning raw `ShowAka(Name, CountryCode, CountryName)` in array order;
  provider parses through the cache + throttle (R14: 404/empty → empty list, transport → throw).
- `IShowMapper.MapAkasAsync(tvmazeId, akas, targetCountry)` — writes source rows verbatim (delete-then-insert,
  a rebuildable child set with no surrogate id), picks the lowest-order aka for the target country into
  `title_localized`, null on no match. Returns `AkaMapResult(Changed, PickedTitle)`.
- `Enrichment --akas` job (`AkasJob`): select active shows, fetch, map, lease-guarded, `items_changed` = the
  mapped-title change. Target country from config (`Localization:TargetCountryCode`, default RU).
- Details-page button (`FetchLocalizedTitlesUseCase`): single-show fetch, no lease, lists every alternate.

## Acceptance criteria (copied from IMPLEMENTATION_PLAN.md)
- [ ] Show `59985` gets `title_localized = 'Начало'` (first RU) and its `tvmaze_akas` rows hold all five akas.
- [ ] A show with no RU aka leaves `title_localized` null (not a wrong-country guess).
- [ ] Re-running reports `items_changed = 0`.
- [ ] The details-page button (step 6.1) on the same show lists all five akas and sets the same `title_localized`.

## Constraints
- The provider must NOT hard-code "RU" — the target country is configuration, applied above the provider.
- The button's use case goes through the mapper (R11), never writes `title_localized` itself.
- `tvmaze_akas` is a source table: read only by the mapper (R11/P3); the button reads the mapped result.
- `MapAkasAsync` is on `IShowMapper` (Application can't name the concrete mapper), so `ShowAka` is an Application type.
