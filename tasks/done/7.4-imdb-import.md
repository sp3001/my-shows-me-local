# Step 7.4 — `ImdbImport` (download/reuse + three-pass bulk load)

## Read
- `docs/IMPLEMENTATION_PLAN.md §Step 7.4` — download/reuse, ADR-021 scoping, bulk-load order, verify criteria.
- `docs/DATA_ANALYSIS.md §6` — the dataset shapes, `\N`→null, and the (corrected) import order.
- `docs/SCHEMA.md §4` — `imdb_title` / `imdb_episode` / `imdb_akas` / `imdb_dataset_meta` columns + the FK.
- `docs/DECISIONS.md ADR-021` (scope to tracked shows), `ADR-028` (lease, no long write transaction).

## Do
- `IImdbDatasetDownloader` + `ImdbDatasetDownloader`: stream a dataset's `.tsv.gz` over the `Imdb` named
  client (`ResponseHeadersRead` so the request timeout covers only headers); write to `.part`, move on
  success; keep the file on disk; report a transport failure, never throw (R14).
- `TsvReader`: streaming plain-or-`.gz` reader, `\N`→null / `\N`→null-int (never 0).
- `ImdbImporter`: reuse a dataset already on disk (`.tsv` or `.tsv.gz`), else download; load only rows
  reachable from active tracked shows (ADR-021, `deleted_at IS NULL`); three passes in the corrected order
  (titles → episodes → episode-details → akas); raw parameterized `Microsoft.Data.Sqlite` batches in
  **short batched transactions** with the lease renewed at each boundary; `INSERT OR IGNORE` + a
  value-guarded `UPDATE` for re-runnability; record `imdb_dataset_meta`.
- `ImdbImportJob` entry point + `Program.cs` handler + DI registration.

## Acceptance criteria (copied from IMPLEMENTATION_PLAN.md)
- [x] `imdb_episode WHERE parent_tconst='tt26448526'` = 33.
- [x] `tt2085059` loads exactly what the source contains (34 now, 32 at planning — see LOG).
- [x] The `.tsv.gz` files still exist after the run (kept, not deleted).
- [x] A second run reports `items_changed = 0`.
- [x] A soft-deleted show's imdb_id is never loaded (ADR-021 / R8).

## Constraints
- Reuse a file already in `data/imdb` — never re-download (a schema change is a re-load, not a re-download).
- Titles before episodes: the `imdb_episode.parent_tconst` FK is checked at each batch commit and cannot be
  deferred across one (ADR-028 forbids one long transaction; the lease renews on a separate connection).
- The importer is the sole writer of the `imdb_*` source tables (rule 5 allow-list) and a bulk writer (rule 8).
- `\N` → NULL throughout, never 0 or empty string.
