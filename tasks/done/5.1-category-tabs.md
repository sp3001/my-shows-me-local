# Step 5.1 — Category tabs and show list (+ untrack)

## Read
- `docs/STATE.md` — current state; consumes the add path (3.2/4.1) and the category read (F4).
- `docs/IMPLEMENTATION_PLAN.md step 5.1` — acceptance criteria (below).
- `docs/SPEC.md F4` — four tabs over `user_show` joined to `tracked_show`, filtered `deleted_at IS NULL`; virtualized list; poster + title + `watched_regular / total_regular`.
- `docs/SPEC.md R1/R3/R4` — exactly four categories; R3 title split; unwatched specials surface as a note.
- `docs/DECISIONS.md` ADR-024 — untracking is a logical delete; phrase it as "removed from tracking, history kept", never "deleted"; no permanent-delete option in v1.
- `Shows.Application/UseCases/ReadUseCases.cs` (`GetCategoryOverviewUseCase`) + `AddShowToTrackingUseCase.cs` (`UntrackShowUseCase`) — the seams the VM drives.

## Do
- `TrackedShowCardViewModel`: wraps a `TrackedShow`; R3 title split, progress `watched_regular / total_regular`
  (null-safe per R7), poster, needs-review + unwatched-specials notes, and an `Untrack` command that runs
  `UntrackShowUseCase` in a per-operation scope then removes the card from its parent list.
- `TrackingViewModel`: the four categories as a selector; loads the selected category via
  `GetCategoryOverviewUseCase` in a scope; `Untrack` on a card removes it from the visible list.
- `TrackingPage.xaml`: a category selector + a virtualized `CollectionView` of cards.
- Register the VM/page in `MauiProgram`; add a "My Shows" tab to `AppShell`.

## Acceptance criteria
- [ ] All four tabs render their real counts; progress matches the cached columns.
- [ ] Untrack a show with watched episodes: it vanishes from the tab, and the row is still in `episode_watch`
      (the visible behaviour and the DB state both have to be right — ADR-024).
- [ ] The untrack message says the show is removed from tracking and its history is kept — not "deleted",
      and no "permanently delete" option is offered.

## Constraints
- The list reads through `GetCategoryOverviewUseCase`, which is already `deleted_at IS NULL` filtered by the
  repository (SPEC R8) — do not re-filter in the VM.
- Untrack runs `UntrackShowUseCase` (sets `deleted_at`); it must NOT delete any row.
- No View/ViewModel names `Shows.Infrastructure` (rule 4); VMs resolve use cases from a per-operation scope.
- Do NOT run `--promote`. Do NOT touch staging tables.
