## Do
Encode each rule as a test, then **for each rule inject a violation, confirm the test fails, remove it,
confirm it passes** — record the injected violation per rule. A passing architecture test that cannot
fail is worthless.

Rules (from the plan):
1. `Shows.Application` references no EF Core / HTTP / MAUI / Newtonsoft types (NetArchTest on the
   Application assembly).
2. No Application signature returns `IQueryable` — already in `ApplicationInterfaceTests`; add the trait.
3. `Shows.Domain` has zero packages (read `Shows.Domain.csproj` for no `<PackageReference>`) and no
   Domain type depends on `Microsoft.*` / `System.Text.Json` / `Newtonsoft` / `System.Net.Http` /
   `System.ComponentModel.DataAnnotations` (the "plain C#, no EF/JSON attributes" half).
4. UI types do not reference Infrastructure outside the composition root — source scan of
   `Shows.App/**/*.cs` (the MAUI assembly can't be loaded from the net8 test project): only
   `MauiProgram.cs` may name `Shows.Infrastructure`.
5. **Source-table containment:** within Infrastructure, the only types that reference the
   `Shows.Infrastructure.Persistence.Sources` (`tvmaze_*`/`imdb_*`) namespace are the mapper, the
   DbContext, the JSON mapper, the fetch seam, and the provider (allow-list). Application has no
   dependency on Infrastructure at all (wrong direction — it can't).
6. **User-data containment:** the mapper has no dependency on `UserShow` or `UiSeasonState`. (It reads
   `EpisodeWatch` to recompute progress — allowed by SPEC P4 — so write-containment of `episode_watch`
   is the behavioral rebuild drill in step 1.5, not a type-level rule.)
7. **No store-generated keys:** build the EF model reflectively and assert no property is
   `ValueGenerated.OnAdd`/`OnAddOrUpdate`; and no migration `.cs` contains `AUTOINCREMENT` (ADR-026/027).
8. **Lease discipline:** the bulk writers (`ImdbIdScraper`, `TvmazeIdResolver`) each take `IWriterLease`
   in their constructor (the type-level half; the behavioral half is step 1.6).

  from `AppContext.BaseDirectory` to the folder containing `Shows.sln`.
- Do not weaken a rule to make it pass; if a legitimate type must be exempt, add it to a named allow-list
  with a one-line reason.
